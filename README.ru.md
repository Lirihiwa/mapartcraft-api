# MapartCraft API

[🇬🇧 English](README.md) | 🇷🇺 Русский

Микросервис на Node.js + Express, который превращает картинку в мапарт для Minecraft.
Это серверная версия [MapartCraft](https://github.com/rebane2001/mapartcraft): она использует те же данные о цветах (`coloursJSON.json`, `ditherMethods.json` и др.) и те же алгоритмы подбора цветов.

Сервис работает в **два шага**, чтобы можно было посмотреть результат до генерации файла:

1. **Превью**: загружаешь картинку и настройки, получаешь превью и список материалов.
2. **Генерация**: просишь `.nbt`-схему, собранную именно из этого превью. Ничего не пересчитывается заново.

## Быстрый старт

Нужен Node.js 16+.

```bash
cd api
npm install
npm start
```

Сервер слушает порт `3000` (меняется переменной окружения `PORT`).

```bash
curl http://localhost:3000/health
# {"status":"ok"}
```

> API читает JSON-файлы из `../src/components/mapart/json/`, поэтому папка `api/` должна лежать внутри репозитория MapartCraft.

## Docker

Собирай образ из **корня репозитория** (образу нужны и `api/`, и JSON-данные из `src/`):

```bash
docker build -f api/Dockerfile -t mapartcraft-api .
docker run --rm -p 3000:3000 mapartcraft-api
```

Порт меняется так: `-e PORT=8080 -p 8080:8080`.

## Пример использования

Создай `settings.json`:

```json
{
    "mapSize_x": 1,
    "mapSize_y": 1,
    "version": "1.20",
    "staircasing": false,
    "dithering": "FloydSteinberg",
    "selectedBlocks": {
        "13": "0",
        "28": "0",
        "27": "0",
        "24": "0",
        "26": "0",
        "17": "0"
    }
}
```

(белая, чёрная, красная, синяя, зелёная и жёлтая шерсть)

**1. Создай превью**

```bash
curl -X POST http://localhost:3000/previews \
  -F "image=@test.png" \
  -F "settings=<settings.json"
```

Ответ:

```json
{
    "previewId": "c0586cd1-871d-4790-b519-66a7c627fbd6",
    "width": 128,
    "height": 128,
    "imageUrl": "/previews/c0586cd1-871d-4790-b519-66a7c627fbd6/image",
    "materials": [
        {
            "colourSetId": "28",
            "blockId": "0",
            "displayName": "Black Wool",
            "count": 8051
        }
    ]
}
```

**2. Посмотри превью** (открой в браузере; параметр `scale` увеличивает картинку методом ближайшего соседа, поэтому пиксели остаются чёткими):

```
http://localhost:3000/previews/<previewId>/image?scale=6
```

**3. Сгенерируй схему**

```bash
curl -X POST http://localhost:3000/previews/<previewId>/nbt -o mapart.nbt
```

Результат это сжатый gzip `.nbt`-файл. Его можно использовать через структурный блок, Litematica, Schematica, cubical.xyz и т.д.

## Справочник API

| Метод  | Путь                  | Описание                                                                                                                                        |
| ------ | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`  | `/health`             | Проверка работоспособности.                                                                                                                     |
| `POST` | `/previews`           | `multipart/form-data` с полями `image` (файл) и `settings` (строка с JSON). Возвращает `previewId`, `width`, `height`, `imageUrl`, `materials`. |
| `GET`  | `/previews/:id/image` | Превью в формате PNG. Необязательный параметр `?scale=1..16`.                                                                                   |
| `POST` | `/previews/:id/nbt`   | Сжатая `.nbt`-схема, собранная из сохранённого превью.                                                                                          |

Ошибки возвращаются в JSON: `{ "error": "..." }` со статусом `400` (неверные данные) или `404` (превью не найдено или устарело).

### Настройки

| Поле                             | По умолчанию         | Описание                                                                                                                       |
| -------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `selectedBlocks`                 | нет, **обязательно** | Объект `colourSetId → blockId` (см. `coloursJSON.json`). `"-1"` значит «не использовать этот цвет». Нужен хотя бы один блок.   |
| `mapSize_x`, `mapSize_y`         | `1`                  | Размер в картах. Одна карта это 128×128 блоков.                                                                                |
| `version`                        | `"1.20"`             | Версия Minecraft для названий блоков (`1.12.2` … `1.20`, см. `supportedVersions.json`).                                        |
| `staircasing`                    | `true`               | `false` для плоской карты (один оттенок на цвет). `true` использует тёмный/обычный/светлый оттенки (в 3 раза больше цветов).   |
| `betterColour`                   | `true`               | Подбор цветов в пространстве Lab вместо RGB.                                                                                   |
| `dithering`                      | `"FloydSteinberg"`   | `None`, `FloydSteinberg`, `MinAvgErr`, `Burkes`, `SierraLite`, `Stucki`, `Atkinson`, `Bayer44`, `Bayer22`, `Ordered33`.        |
| `cropMode`                       | `"center"`           | `center`, `manual` или `off` (растянуть).                                                                                      |
| `zoom`, `percent_x`, `percent_y` | `10`, `50`, `50`     | Ручной кроп: зум `10..50` (10 = вся картинка), смещения `0..100`.                                                              |
| `preprocessing`                  | выключено            | `{ "enabled": true, "brightness": 100, "contrast": 100, "saturation": 100 }`, каждое значение `0..200`, `100` = без изменений. |
| `supportBlock`                   | `"cobblestone"`      | Блок для noobline (лишнего ряда блоков, который задаёт оттенок первой строки карты).                                           |

## Текущие ограничения

Это первая версия, поэтому учти следующее:

- Генерация `.nbt` работает **только для плоских карт** (`"staircasing": false`). Превью со ступеньками создаются, но `/nbt` пока их отклоняет.
- Генерируется только noobline. **Подпорки** под песок, ковры, нажимные плиты и т.п. пока не ставятся.
- **Экспорт `map.dat` ещё не реализован.**
- Превью хранятся **в памяти**: живут 30 минут, не больше 200 одновременно, и пропадают при перезапуске.
- Нет авторизации и ограничения частоты запросов. В таком виде не выставляй сервис в интернет.
- Яркость, контраст и насыщенность считаются через `sharp`, а не через CSS-фильтры браузера, поэтому результат может немного отличаться от сайта.

## Как внести вклад

Мы будем рады любому вкладу: баг-репортам, идеям, документации и коду. 🙌

1. Сделай форк репозитория и создай ветку (`git checkout -b feature/my-feature`).
2. Выбери задачу из плана выше или сначала открой issue, чтобы обсудить идею.
3. Сохраняй поведение таким же, как на сайте MapartCraft: одна и та же картинка с теми же настройками должна давать тот же результат.
4. В pull request опиши, как ты проверял изменения.
